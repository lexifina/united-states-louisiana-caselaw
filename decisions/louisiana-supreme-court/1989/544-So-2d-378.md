# State v. Cager

## Majority

MOTION TO WITHDRAW APPLICATION GRANTED
Defendant Mitchell, Cager, by counsel, hereby withdraws his application for supervisory writs requesting reversal of a finding of probable cause for first degree murder by an ad hoc magistrate in Orleans Parish. By joint request with the state, another magistrate has reconsidered the issue of probable cause, has found probable cause only for second degree murder, and has set bond. The writ application is therefore moot.
