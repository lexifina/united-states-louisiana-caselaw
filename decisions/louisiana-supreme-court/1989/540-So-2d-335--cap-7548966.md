# State ex rel. Deloch v. Iberville Parish, 18th Judicial District Court

Granted. The district court is ordered to comply with this Court’s order of September 28, 1988, 531 So.2d 256 to rule on relator’s application for post-conviction relief filed via certified mail on April 27, 1988.
