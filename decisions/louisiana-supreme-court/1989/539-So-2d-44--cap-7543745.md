# State ex rel. Moore v. State

## Majority

Granted. Relator may file an out-of-time application for certiorari on any constitutional issues which have already been decided by the lower courts. State v. Jacobs, 504 So.2d 817 (La.1987).

## Concurrence (CALOGERO, J.,)

CALOGERO, J.,
concurs. Relator may be able to get relief from this final conviction if he can establish that he had a meritorious assignment of error of non-constitutional proportion which went by the wayside because of ineffective assistance of counsel.
