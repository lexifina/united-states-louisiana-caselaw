# State v. Square

## Majority

In re: James Willie Millsaps applying for writ of certiorari.
The application is denied, reserving to the defendant his right to file an “Application for Admission to Bail”, as provided in Art. 313 of the Code of Criminal Procedure.
McCALEB, J., is of the opinion that the application should be granted.

## Concurrence (SUMMERS, J.,)

SUMMERS, J.,
concurs in the refusal of the application but does not agree that the reservation of 'rights is an appropriate part of the court’s disposition.
