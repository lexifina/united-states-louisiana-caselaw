# Same v. Same

## Majority

This suit is brought to recover the two last instalments of the same debts on which that already decided, is founded. It differs nothing in principles from the former, except that in this it appears that one of the defendants is a resident of the parish wherein the actions commenced; which is a circumstance by no means calculated to induce a different decision.
It is therefore ordered that the same judgment be entered,&c.
