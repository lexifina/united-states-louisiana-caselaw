# State v. Glasper

## Majority (LEMMON, Justice.)

LEMMON, Justice.
For the reasons assigned in State v. Fraser, 484 So.2d 122 (La.1986), the portion of the judgment of the court of appeal which set aside the sentence is itself set aside, and the sentence imposed by the trial court is reinstated.
