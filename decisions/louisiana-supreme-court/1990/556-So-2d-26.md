# Rufty v. Louisiana State Bar Ass'n

## Majority

In re Rufty, Alfred J. Ill; — Plaintiff(s); applying for permission to submit late application to take LA. State Bar Exam.
It is hereby ordered that Alfred J. Rufty, III be granted an extension for submitting his application for the February 1990 sitting of the Louisiana State Bar Examination until January 5, 1990.
