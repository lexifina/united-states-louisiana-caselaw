# State v. Nattin

## Majority

In re: State of Louisiana through D. A. Charles A. Marvin, applying for writs of Certiorari, prohibition and mandamus.
Writ refused. The State’s remedy was by appeal. See Article 912, Louisiana Code of Criminal Procedure. The delay for appeal had expired prior to the filing of this writ application. See Article 914, LSA-C.Cr.P.
