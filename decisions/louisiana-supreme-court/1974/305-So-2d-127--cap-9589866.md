# State v. Marullo

## Majority

In re: State of Louisiana applying for remedial writs.
Writ granted. The ruling of the trial judge is reversed and set aside and a new evidentiary hearing is ordered on the motion to suppress.
DIXON, J., is of the opinion that there is no error in the ruling of the trial judge.
CAL'GGERO, J., took no part.
