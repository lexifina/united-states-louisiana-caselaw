# State v. Hatcher

## Majority

In re: Gerald Hatcher applying for supervisory writs.
Writ refused. On the showing made, there is no basis for the exercise of our supervisory jurisdiction at this time. Questions of bail are not res judicata and remain open. Relator’s right to file a new application with the trial court is not precluded.
