# State ex rel. Majors v. Shea

## Majority

In re: Sylvester K. Majors, applying for writs of certiorari, and/or review, mandamus and prohibition.
Writ granted. Relator has failed to first make application to the district court for relief sought. Hence relator’s application will be transferred to the district court so that district judge can act on relator’s application. See Art. 913, C.Cr.Pr. and State ex rel. Mathews v. Henderson, 292 So.2d 496.
