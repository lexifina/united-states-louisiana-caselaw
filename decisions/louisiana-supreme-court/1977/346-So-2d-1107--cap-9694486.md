# State ex rel. Hammond v. Maggio

## Majority

In re: Forrest Hammond applying for remedial writ of certiorari.
Writ refused. The main contention made here was rejected in the relator’s prior application. See State ex rel. Hammond v. Henderson, La., 338 So.2d 301. In all other respects, the application is without merit.
DENNIS, J., is of the opinion that the writ should be granted and an evidentiary hearing ordered.
