# State ex rel. Backert v. Walker

## Majority

In re: Judy D. Backert aka Judy D. Tallent, applying for writ of Habeas Corpus.
Writ denied. Application is without merit.

## Dissent (DIXON, J.,)

DIXON, J.,
dissents from the denial. When the federáis convict for robbing a bank, the state should not be permitted to prosecute again for the same offense. (If the accused is acquitted in the federal system, he cannot again be tried in the state courts).
