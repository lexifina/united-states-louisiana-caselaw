# State v. McGee

## Majority

In re: Eddie J. McGee, Jr. applying for supervisory writs.
Application denied; without reaching the merits of the application, we notice the trial is fixed for Oct. 19. We will not interfere with the orderly proceedings in the court below, since there is an adequate remedy by review in the event of conviction.
