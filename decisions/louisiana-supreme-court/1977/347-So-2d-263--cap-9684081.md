# State ex rel. Williams v. Honorable Judge Presiding Criminal District Court Parish of Orleans

## Majority

In re: Cleveland Williams and Michael Herbert applying for writ of mandamus.
Writ denied: We find this mandamus application to be moot, based upon an oral return from the district court that it has acted upon the habeas petition. The district court is instructed to send the applicants a copy of its ruling, if it has not done so already.
