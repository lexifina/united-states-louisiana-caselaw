# In re Committee Bar Admissions CFN-473690

## Majority

IN RE: Confidential Party; Plaintiff; Applying For Petition to sit for the Louisiana Bar July 7, 2017
11 Granted. Petitioner is allowed to take the Louisiana State Bar Examination. Within fifteen days of notification that he has satisfactorily passed this examination, petitioner may file a brief with this court, supported by appropriate documentary evidence, demonstrating that he has made a good faith effort to address the default judgment against him.
