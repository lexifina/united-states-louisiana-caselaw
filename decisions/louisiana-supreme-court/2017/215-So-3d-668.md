# State ex rel. Bunch v. State

## Majority (PER CURIAM:)

PER CURIAM:
| TPenied. Relator’s sentencing claim is not cognizable on collateral review. La. C.Cr.P. art. 930.3; State ex rel. Melinie v. State, 93-1380 (La. 1/12/96), 665 So.2d 1172; see also State v. Cotton, 09-2397 (La. 10/15/10), 45 So.3d 1030. Relator has exhausted his right to collateral review. See State ex rel. Bunch v. State, 15-1672 (La. 4/13/17), 215 So.3d 664.
