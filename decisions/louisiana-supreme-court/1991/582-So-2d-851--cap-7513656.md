# State ex rel. Lewis v. State

## Majority

In re Motion to enforce order dated September 19, 1990; Parish of Orleans, Criminal District Court, Div. “A”, No. 256-705.
Granted. On April 9, 1991, the trial court ordered the state to file an answer to relator’s petition within thirty days. This motion to enforce is transferred to the district court for enforcement of the April 9th order and for a ruling on relator s pending application.
