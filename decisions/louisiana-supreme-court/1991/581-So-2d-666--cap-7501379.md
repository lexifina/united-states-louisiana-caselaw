# In re Robarts

## Majority

In re Robarts, Judith M.; — Plaintiff(s); applying for Late application to sit for the Louisiana Bar Examination.
It is hereby ordered, decreed and adjudged that Judith M. Robarts, be allowed to file a late application with the Louisiana State Bar Association and to take the July, 1991 Bar Examination.
