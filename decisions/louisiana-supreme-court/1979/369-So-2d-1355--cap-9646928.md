# State ex rel. Johnson v. Orleans Indigent Defender Program

## Majority

In re Michael Johnson applying for remedial writ. Parish of Orleans. No. 263—303.
Writ denied. Although the appeal was taken January 2, 1978, the return from the OIDP shows that neither the transcript nor the assignments of error have as yet been filed. The application is therefore premature.
