# State ex rel. Barefield v. Roberts

## Majority

In re Erick Barefield, applying for writ of habeas corpus. East Baton Rouge Parish.
Writ granted. The relator alleges he has filed a request for preliminary examination which has not been acted upon, although he has been held in prison since December 17, 1978. We transfer this writ to the trial court for appropriate action.
