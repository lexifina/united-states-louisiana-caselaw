# State ex rel. Stewart v. Shiell

## Majority

In re Charles Stewart, applying for writ of mandamus. Parish of Orleans, Number 252-328.
Denied.

## Concurrence (DIXON, J.,)

DIXON, J.,
concurs in the denial. If the applicant wants an out-of-time appeal, he must file in the district court and request it. He does not need his transcript for that purpose.
