# State ex rel. Newton v. Harville

## Majority (HAWTHORNE, Justice.)

HAWTHORNE, Justice.
For the reasons given in our opinion in No. 43142, In re Harville Applying for Adoption, 233 La. 1, 96 So.2d 20, the judgment of the district court is reversed and set aside, and the case is remanded for proceedings consistent with the views which we have expressed.
McCALEB, J., concurs for the reasons given in No. 43142.
