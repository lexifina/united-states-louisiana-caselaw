# State ex rel. Williams v. State

## Majority

In re Williams, August; — Plaintiffs); applying for supervisory and/or remedial writ; Parish of Orleans, Criminal District Court, Div. “F”, No. 202-536.
Writ granted in part; relator’s sentence is amended to delete the denial of parole eligibility. See State v. Craig, 340 So.2d 191, 193 (La.1976); State v. Singleton, 263 La. 267, 268-69, 268 So.2d 220, 221 (1972); State v. Franklin, 263 La. 344, 268 So.2d 249 (1972). In all other respects, the application is denied.
