# State ex rel. Evans v. Henderson

## Majority

In re: Daryl Evans applying for writ of habeas corpus.
The application is denied. We find no merit in the application and we agree with the trial judge that the question now raised was disposed of in the original prosecution. See State v. Evans, 249 La. 861, 192 So.2d 103.
