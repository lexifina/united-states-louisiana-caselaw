# State v. Maurice

## Majority (liPER CURIAM .)

liPER CURIAM .
Granted in part. The district court is ordered to issue a subpoena duces tecum for the file of the state witness and to conduct an in camera inspection of the materials to determine if there is any exculpatory or impeachment evidence in the file. Otherwise, the application is denied.
