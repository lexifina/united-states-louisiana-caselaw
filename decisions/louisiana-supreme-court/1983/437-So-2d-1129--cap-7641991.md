# State ex rel. Edwards v. Hathaway

## Majority

In re Frank Edwards, applying for writ of habeas corpus. Parish of Caddo. No. 111865.
Granted. This application is transferred to the district court for action. The clerk should receive and file all habeas applications; he does not have the authority to deny applications for habeas corpus or post-conviction relief.
