# State v. Romious

## Majority (PER CURIAM.)

PER CURIAM.
| iApplication denied. We have carefully considered the application pursuant to Code of Criminal Procedure article 672, which provides that on the “written application of a trial judge, the supreme court may recuse him for any reason that it considers sufficient.” We agree with the applicant that there is no basis to recuse Judge Ellen Shirer Kovach from hearing the motion to recuse Judge Steven En-right. Therefore, the application is denied.
WEIMER, J., dissents.
