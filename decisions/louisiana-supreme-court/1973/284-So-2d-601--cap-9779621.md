# State ex rel. Polk v. Henderson

## Majority

In re: Frank Polk, Jr. applying for remedial writ of habeas corpus, mandamus, prohibition or others.
Writ denied. The showing does not warrant the granting. A guilty plea waives all rights save jurisdictional defects. State v. Valentine, 259 La. 1019, 254 So.2d 450 (1971); State v. Miles, 261 La. 663, 260 So.2d 661 (1972).
BARHAM, J., concurs.
