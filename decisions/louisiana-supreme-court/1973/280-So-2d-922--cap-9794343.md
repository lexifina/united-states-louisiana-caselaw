# State ex rel. Gantt v. Oakes

## Majority (DIXON, J.,)

In re: Mildred Gantt applying for writ of habeas corpus.
Not considered. This court does not en- „ tertain a petition for habeas corpus until remedies have been exhausted in the trial court. See Comment (a), Art. 352, Louisiana Code of Criminal Procedure.
