# State ex rel. Escobar v. Henderson

## Majority

In re: Ricardo Escobar applying for writs of mandamus and habeas corpus.
Application not considered. The return of the clerk of the trial court of September 5, 1973 shows that there is no record that the application was filed in the trial court. This Court will not consider a post-conviction application or contentions raised for the first time in this Court.
