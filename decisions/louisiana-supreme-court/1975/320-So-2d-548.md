# State v. Brady

## Majority

In re: State of Louisiana applying for appeal, etc.
Writ granted. Ruling of trial judge set aside; evidentiary hearing on motion to suppress the evidence is ordered. Application was timely filed by mail.

## Concurring in part and dissenting in part (SUMMERS, J.,)

SUMMERS, J.,
I agree that there is merit in this application. However, I have doubts that this Court should order this hearing without giving the trial judge an opportunity to be heard in this Court.
