# State ex rel. Brown v. Henderson

## Majority

In re: Bertrand Brown applying for writ of mandamus.
Writ denied. The relator’s new trial, ordered by this court, is fixed for January 19, 1976. Insofar as his application might be considered a request for release on bail, we do not consider it, since it has not been presented to the trial court.
