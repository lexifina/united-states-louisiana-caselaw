# State v. Brumley

## Majority

In re: William R. Brumley, applying for writs of certiorari.
Writ denied. There is no error of law. See State v. Holmes, 263 La. 685, 269 So. 2d 207 and State v. Flood, 263 La. 700, 269 So.2d 212.

## Concurrence (CALOGERO, J.,)

CALOGERO, J.,
concurs. While disagreeing with this Court’s decisions in State v. Holmes, State v. Flood and State v. Rhymes, 284 So.2d 923, I am constrained to follow these majority decisions of this Court.
