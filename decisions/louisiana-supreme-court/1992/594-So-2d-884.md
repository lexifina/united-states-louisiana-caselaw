# State ex rel. Green v. Whitley

## Majority

In re Green, Milton, J.; — Plaintiff(s); applying for supervisory and/or remedial writ; Parish of Lafourche, 17th Judicial District Court, Div. “D”, No. 68167.
Granted in part; denied in part. Relator’s sentence is vacated and this case is remanded to the district court for resen-tencing in accord with the procedures and guidelines set forth in State v. Husband, 593 So.2d 1257 (La.1992), and State v. Desdunes, 579 So.2d 452 (La.1991). In all other respects, the application is denied.
