# In re Bonnie

## Majority

In re Bonnie, Terry L.; — Plaintiff(s); applying for permission to submit late application to take bar examination.
It is hereby ordered that Terry L. Bonnie, be permitted to submit application for the taking of the Louisiana State Bar Ex-animation which begins on February 10, 1992.
