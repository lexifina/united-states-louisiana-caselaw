# State v. Robertson

## Majority

In re Robertson, Derek; — Defendant(s); applying for supervisory and/or remedial writs; Parish of Orleans, Criminal District Court, Div. “D”, No. 269-882.
Granted. Relator’s sentence is vacated and this case is remanded to the district court for resentencing in accord with the procedures outlined in State v. Husband, 593 So. 1257 (La.1992) and State v. Desdunes, 579 So.2d 452 (La.1991).
