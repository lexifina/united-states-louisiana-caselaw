# State ex rel. Davis v. Dees

## Majority

In re: Courtland Davis applying for writ of certiorari. Parish of East Baton Rouge.
Writ granted. An evidentiary hearing is ordered to determine if plea bargain was violated, in which case trial judge should either amend the sentence or allow withdrawal of plea.
