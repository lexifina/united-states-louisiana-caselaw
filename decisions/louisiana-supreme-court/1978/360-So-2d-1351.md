# State v. Winiarski

## Majority

In re: Marline Winiarski applying for writ of review. Parish of Catahoula.
Writ granted. Ruling of the trial judge denying motion to suppress is set aside; case remanded to district court for new suppression hearing in accordance with law. La.Code Crim.P. art. 703 C. See State v. Schmidt, 359 So.2d 133 (La.1978); State v. Braud, 357 So.2d 545 (La.1978); State v. Franklin, 353 So.2d 1315 (La.1977).
