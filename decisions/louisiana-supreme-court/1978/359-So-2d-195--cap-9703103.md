# State v. Collums

## Majority

In re: Hal R. Collums applying for supervisory writs. Parish of Orleans.
Granted; the ruling of the trial judge that the request for subpoena is “burdensome” is set aside, and an evidentiary hearing is ordered to determine whether production of the requested information would in fact be “burdensome”.
