# State ex rel. Spates v. Maggio

## Majority

In re: Bobby Ray Spates applying for writ of habeas corpus. Parish of Caddo.
The order to the trial judge to appoint counsel and resentence applicant with benefit of counsel is annulled and set aside. This application is denied. See also # 58107 on the docket of this Court.
