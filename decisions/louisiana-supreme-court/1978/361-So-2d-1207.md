# State v. Gwinn

## Majority

In re: Albert Gwinn applying for writs of certiorari, prohibition and mandamus. Parish of East Baton Rouge.
Writ granted: The death penalty is not applicable here. See: State v. Lewis, 353 So.2d 703 (La.1977); State v. Smith, 351 So.2d 1191 (La.1977); State v. Brooks, 351 So.2d 1197 (La.1977); State v. Lee, 340 So.2d 180 (La.1976). The case is remanded for trial.
