# State v. Lee

## Majority (PER CURIAM.)

PER CURIAM.
The issue of whether defendant was denied effective assistance of counsel is more properly raised by application for writ of habeas corpus at which time a full eviden-tiary hearing can be conducted. State v. Anthony, 347 So.2d 483 (La.1977); State v. Ross, 343 So.2d 722 (La.1977); State v. Mouton, 327 So.2d 413 (La.1976).
Finding no reversible error based on the record before us, defendant’s conviction and sentence are affirmed.
