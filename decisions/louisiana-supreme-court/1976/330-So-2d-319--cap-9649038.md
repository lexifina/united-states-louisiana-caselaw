# State ex rel. Winder v. Phelps

## Majority

In re: Isaac Winder applying for Writs of Certiorari, Mandamus and Habeas Corpus.
Writ denied. The application is moot. The trial court has ruled, denying applicant’s petition for habeas corpus; furthermore, with respect to applicant’s request for evidentiary hearing in this writ application, the trial judge advises that on an earlier identical application, an evidentiary hearing was held and the habeas application denied with reasons.
