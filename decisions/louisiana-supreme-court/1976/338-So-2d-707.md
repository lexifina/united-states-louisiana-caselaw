# State ex rel. Robinson v. D'Artois

## Majority

In re: Prentice Robinson, Jr. applying for Writ of Certiorari.
Writ denied. The application does not set forth grounds for relief under La.R.S. 44:1 et seq. See La.R.S. 44:32-34. The application is denied without prejudice to any right to obtain access to the records in connection with a pending application for post-conviction relief.
