# State ex rel. Smith v. Maggio

## Majority

In re: Lawrence Joseph Smith, applying for writ of habeas corpus.
Writ denied. The defendant is not entitled to credit for pre-sentence incarceration against a sentence imposed prior to the 1970 amendment of La. Code of Crim. Procedure, Art. 880. See State v. Williams, 262 La. 769, 264 So.2d 638 (1972).
