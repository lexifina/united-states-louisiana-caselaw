# State v. Robinson

## Majority

In re: Donald K. Robinson applying for writs of certiorari, prohibition and mandamus.
Writ denied. Because applicant’s trial is definitely set for Dec. 6, 1976 and because he has an adequate remedy on appeal in the event of conviction with respect to the alleged errors, this application is denied.
