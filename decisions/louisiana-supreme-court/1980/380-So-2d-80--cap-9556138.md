# State v. Richardson

## Majority

In re Carol Richardson, applying for supervisory writs. Orleans Parish. No. 257-125.
Denied.
CALOGERO, J., would grant and order an evidentiary hearing.

## Concurrence (DIXON, J.,)

DIXON, J.,
assigns additional concurring reasons: Although relator makes a showing which would entitle him to an evidentiary hearing, the allegations are so incredible and stale that the application should be denied. See the reasons for judgment of the trial judge dated June 28, 1979.
