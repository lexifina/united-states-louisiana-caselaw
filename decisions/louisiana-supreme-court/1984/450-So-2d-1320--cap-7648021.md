# In re Sinclair

## Majority

In re Scott C. Sinclair, applying for permission to file late application to take Bar Examination.
Granted. Committee on Bar Admissions, Louisiana State Bar Association is ordered to accept relator’s application notwithstanding it is filed late, and permit relator to take the bar examination scheduled for July 16, 1984 if the application is otherwise in proper order and if relator is otherwise qualified.
