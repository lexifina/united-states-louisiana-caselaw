# In re Patrick for Permission to Take the July Bar Exam

## Majority

ORDER GRANTING PETITIONER PERMISSION TO PILE HIS APPLICATION IMMEDIATELY WITH THE COMMITTEE ON BAR ADMISSIONS OF THE STATE OP LOUISIANA
Petitioner in the above-captioned matter has applied to this Court for permission to file late to take the July 1984 Louisiana State Bar Examination.
This Court grants permission to the petitioner to file his application immediately with the Committee on Bar Admissions of the Louisiana State Bar Association.
