# State ex rel. Lowe v. Henderson

## Majority

In re: James Edward Lowe, Thomas Barnes, Jr. and Isreal Anderson McCready applying for remedial writs and writs of habeas corpus.
Application denied; this is a subsequent application, and this Court has already reviewed applicants’ principal complaints. (261 La. 472, 259 So.2d 918). The complaint of delay is moot. The contention concerning court costs in the previous proceeding is not properly before us.
