# State ex rel. Thompson v. Henderson

## Majority

In re: Robert M. Thompson applying for writ of habeas corpus.
Writ denied. All issues presented by this application have been adjudicated in the original prosecution. See State v. Thompson, 256 La. 1019, 240 So.2d 899 (1970). This Court will not again pass upon issues already finally litigated. State ex rel. Barksdale v. Dees, 252 La. 434, 211 So.2d 318.
