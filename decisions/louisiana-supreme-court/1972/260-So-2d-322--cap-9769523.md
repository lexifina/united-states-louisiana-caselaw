# State v. Williams

## Majority

In re: Captain Joseph Young Williams, III applying for writ of prohibition, cer-tiorari and mandamus with stay order.
Writ refused. The application is premature in consideration of the trial judge’s return and subsequent action in this matter. Relator’s rights are fully reserved to reapply should an adverse judgment be ultimately rendered against him.
