# State v. Alexander

## Majority

In re: Claude Alexander and Lee Perry Pratt applying for writ of habeas corpus and for a stay order.
Application denied. We perceive no error in the rulings below. Relators are not entitled to the relief sought.

## Dissent (BARHAM, J.,)

BARHAM, J.,
is of the opinion the writ
should be granted ordering bail under Code criteria. See dissents in State v. Flood, 263 La.-, 269 So.2d 212 and State v. Holmes, 263 La. —, 269 So.2d 207.
