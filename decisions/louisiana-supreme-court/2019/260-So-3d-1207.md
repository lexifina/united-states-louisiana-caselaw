# Huntsman Int'l, LLC v. Praxair, Inc.

## Majority (I would grant and docket this application to examine whether Code of Judicial Conduct Canon 3(C) provides an additional ground for recusal independent from the grounds enumerated in La. Code Civ. P. art. 151. In my view, the original per curiam, which recused a respected member of the judiciary, will lead to confusion in the trial courts as to the proper standard for judicial recusal in Louisiana.)

I would grant and docket this application to examine whether Code of Judicial Conduct Canon 3(C) provides an additional ground for recusal independent from the grounds enumerated in La. Code Civ. P. art. 151. In my view, the original per curiam, which recused a respected member of the judiciary, will lead to confusion in the trial courts as to the proper standard for judicial recusal in Louisiana.
