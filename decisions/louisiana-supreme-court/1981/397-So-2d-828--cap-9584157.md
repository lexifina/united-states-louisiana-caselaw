# State v. Baldwin

## Majority

In re Timothy George Baldwin, applying for stay of execution and post-conviction relief. Parish of Ouachita. No. 38292.
The request for stay order and the application are denied. Although we disagree with the trial judge’s opinion that he lacked jurisdiction to rule on this application, since this Court has original jurisdiction, we deny the application.
